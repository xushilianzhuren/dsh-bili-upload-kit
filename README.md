# dsh-bili-upload-kit · B站投稿工具箱

Bilibili web-upload SOP as a plugin: **persistent-profile login** (device fingerprint fixed → risk-control treats you as regular, cookies last weeks) + browser-automation script skeleton (upload → form → declaration → submit).

## 工具 `bili_upload_kit`
环境体检 + 持久档案登录命令链 + playwright投稿脚本骨架七步（含**创作声明处理**——JS直选最稳）。

## 风控三不
不连投（间隔≥10分钟）·不标题党马甲·不动别人账号。

## 声明诚实
AI配音/AI形象=明牌选「含AI生成内容」——不是义务是信任资产。
